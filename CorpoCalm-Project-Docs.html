1. Project Overview

CorpoCalm Gateway is a web-based job screening and technical assessment platform. It allows HR teams to publish job postings with custom screening questions, share a portal link with candidates, and automatically score submitted assessments. HR can view all results, scores, and answers from a dedicated dashboard.

4. Complete Application Flow

Step 1: HR opens admin.html → Fills job title, description, skills, location, salary, experience → Sets time limit and passing score → Enters screening questions (one per line) → Enters Admin API Key and clicks "Publish Job" → Gets a shareable link: job-portal.html?job=JOB_ID Step 2: HR shares the link via email / LinkedIn / job boards Step 3: Candidate opens the link → Sees full job card (title, location, salary, skills, description) → Clicks "Apply Now" → Rules popup appears (timer, no tab switch, 2 attempts, no refresh) → Clicks "No Thanks" → sees Thank You message, closes tab → Clicks "I Accept, Start Test" → redirected to index.html Step 4: Candidate takes the test (index.html) → Test auto-loads (no Job ID typing needed) → Fills name and email → Answers questions within the time limit → Timer auto-submits if time runs out → Clicks Submit → sees "Test Submitted Successfully" → No score shown to candidate Step 5: HR checks dashboard.html → Clicks Load/Refresh → Sees candidate name, email, AI score, pass/fail, tab switches → Clicks "View Answers" to read full responses

7. AI Scoring System

Scoring is calculated automatically on the backend when a candidate submits. Each answer is scored out of 100 and the final score is the average across all answers.

FactorMax PointsHow It Works
Answer Length60 pts80+ words=60, 50+=50, 30+=38, 15+=25, 5+=10, blank=0
Technical Keywords40 ptsEach keyword hit = 8 pts. Max 5 keywords = 40 pts

Keywords checked include: api, database, index, query, cache, authentication, jwt, docker, microservice, sql, git, rest, algorithm, async, and 50+ more technical terms.

Final score determines Pass/Fail based on the passing_threshold set per job (default 70%).

8. Security Features

FeatureHow It Works
Admin API KeyRequired to publish jobs. Sent as X-API-KEY header. Set in .env file.
Supabase Keys HiddenKeys only in backend .env. Frontend never touches Supabase directly.
Tab Switch TrackingEvery tab switch is counted and shown to HR in dashboard.
Max 2 AttemptsEnforced at database level with a UNIQUE constraint.
XSS PreventionAll user-provided text is HTML-escaped before rendering.
Input ValidationPydantic models validate all incoming data on backend.

9. How to Run Locally
